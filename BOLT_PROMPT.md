# Cstyle E-commerce Website - Complete Bolt Prompt

## 🎯 Project Overview

Build a complete modern e-commerce website for **Cstyle**, a premium clothing brand and garment manufacturer from Sri Lanka. Create a luxury-modern aesthetic that showcases local craftsmanship meeting contemporary fashion.

**Brand Identity:**
- Name: Cstyle
- Industry: Fashion Garments & Manufacturing
- Team: 30 employees (boutique garment operation)
- Tone: Trendy, confident, creative
- Tagline: "Crafted with Passion. Worn with Pride."

## 🎨 Design System & Color Palette

**Primary Colors:**
- Deep Charcoal Black: `#0D0D0D` (primary background)
- Elegant Gold: `#D4AF37` (primary accent)
- Soft Beige: `#F5E6CC` (secondary accent)
- Pure White: `#FFFFFF` (light mode background)
- Light Text: `#F1F1F1` (dark mode text)
- Dark Text: `#1A1A1A` (light mode text)

**Typography:**
- Headings: "Poppins" or "Urbanist" (bold, modern)
- Body: "Inter" (clean, readable)
- Accent: Custom serif for luxury touches

**Design Elements:**
- Glassmorphism effects with subtle blur
- Grid-based product layouts
- Smooth dark/light mode toggle with fade transitions
- Luxury minimalist aesthetic
- Premium spacing and typography hierarchy

## 🛠️ Technical Requirements

**Tech Stack:**
- React 18+ with TypeScript
- TailwindCSS for styling
- Ant Design components
- Framer Motion for animations
- Lucide React for icons
- React Router for navigation

**Features:**
- Fully responsive (mobile-first design)
- Dark/Light mode with smooth transitions
- Lazy loading and performance optimization
- SEO-friendly structure
- Accessibility compliant

```
Build a complete luxury e-commerce website for Cstyle, a premium clothing brand from Sri Lanka, using React, TypeScript, TailwindCSS, Ant Design, and Framer Motion.

DESIGN REQUIREMENTS:
- Luxury-modern aesthetic with black (#0D0D0D), gold (#D4AF37), and beige (#F5E6CC) color palette
- Dark/light mode toggle with smooth transitions

PAGES TO CREATE:
1. Home: Hero with video background, featured products, categories, testimonials
2. Shop: Filterable product grid with hover animations and quick preview
3. Product Detail: Image carousel, size/color selection, add to cart
4. About: Company story, team photos, Sri Lankan craftsmanship showcase
5. Cart & Checkout: Modern drawer cart, multi-step checkout process
6. Contact: Form, map, business information

KEY FEATURES:
- Shopping cart with add/remove/update functionality
- Product search and filtering system
- Wishlist/favorites functionality
- User authentication (login/signup)
- Dummy "try-on" preview feature
- Newsletter signup modal
- Smooth page transitions and micro-interactions

ANIMATIONS:
- Framer Motion for page transitions and element animations
- 3D hover effects on product cards
- Scroll-triggered animations
- Floating particles and fabric texture effects
- Smooth dark/light mode transitions

CONTENT:
- Sample products for men, women, and kids clothing
- Company information highlighting 30-employee Sri Lankan operation
- Testimonials and social proof elements
- "Crafted with Passion. Worn with Pride." brand messaging

Create a premium, production-ready e-commerce platform that showcases local craftsmanship meeting modern fashion, with elegant animations and luxury design elements throughout.
```
